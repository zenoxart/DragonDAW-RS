Sets the space.

Part of **Reliquary (convolution reverb)** – Convolution reverb. Built-in rooms, halls, a plate, a spring, speaker cabinets and a telephone line, or any impulse-response file; size stretches the response, damping darkens its tail.

**Range:** Options: Small room, Studio room, Chamber, Concert hall, Cathedral, Plate, Spring, Cabinet 1×12, Cabinet 4×12, Telephone (default: Concert hall)

## Mathematics

The built-in response: small and studio rooms ($T_{60}$ 0.45 / 0.8 s at 500 Hz), chamber (1.4 s), concert hall
(2.3 s), cathedral (4.5 s), plate (2 s, dense from the first sample, bright), spring, two speaker cabinets and a
telephone line. With an impulse-response file loaded, the file is used instead.

**Knob position → value.** A choice of 10: the value is the option's index $0 \dots 9$.

**Smoothing.** Takes effect at once (no glide).

Right-click the control for its menu: **Set value…** (a box with the current value: type a new one in the control's units – `-6 dB`, `250 ms`, `2.5k`, `30L` – and press Enter; one undo step), **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
