# Talon (transient shaper) › Sustain › Sustain duration

[Back to Sustain](../README.md) · [Talon (transient shaper)](../../README.md)

Sets the sustain duration.

Part of **Talon (transient shaper)** – Transient designer: attack (Needle / Nail / Blunt) and sustain (Linear / Non-linear / Soft linear) sections with level, sensitivity, duration and shape, mix, output, and a guard (Off / Clip / Limit / Soft clip) after the output.

**Range:** 10.0 ms … 2000 ms (default: 250 ms, logarithmic scale)

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
