# Wingspan (stereo imager) (imager)

*Utility*

Widens the stereo image and keeps the bass mono; a goniometer and correlation meter show the phase relation of the result.

The preset bar on top of the unit holds 200 factory presets in eight characters (Subtle, Warm, Bright, Punchy, Wide, Dark, Heavy, Creative) and your own presets.
