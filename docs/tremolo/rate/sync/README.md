# Wingbeat (tremolo / auto-pan) › Rate › Sync

[Back to Rate](../README.md) · [Wingbeat (tremolo / auto-pan)](../../README.md)

Locks the timing to the song's tempo in note values instead of free milliseconds / Hz.

Part of **Wingbeat (tremolo / auto-pan)** – Tempo-synced volume or pan modulation.

**Range:** Options: Free, 1/32, 1/16, 1/16 dotted, 1/8 triplet, 1/8, 1/8 dotted, 1/4 triplet, 1/4, 1/4 dotted, 1/2, 1 bar (default: 1/8)

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
