# Alembic (filter) › Filter A › Style

[Back to Filter A](../README.md) · [Alembic (filter)](../../README.md)

Chooses the variant of the processing; each option changes the character of the effect.

Part of **Alembic (filter)** – Filter: two filters (serial or parallel), low / high / band pass, notch, peak and shelves, 12 / 24 / 48 dB slopes, styles (clean, smooth, ram, hack), drive, stereo spread, LFO and envelope follower.

**Range:** Options: Clean, Smooth, Ram, Hack (default: Clean)

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
