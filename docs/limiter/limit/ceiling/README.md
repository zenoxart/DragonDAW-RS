# Lodestone (limiter) › Limit › Ceiling

[Back to Limit](../README.md) · [Lodestone (limiter)](../../README.md)

The highest level the output may reach.

Part of **Lodestone (limiter)** – Look-ahead brickwall limiter with true-peak detection, eight styles (Allround, Transparent, Punchy, Dynamic, Aggressive, Modern, Bus, Safe) and 2× / 4× oversampling for mastering.

**Range:** -12.0 dBTP … 0.00 dBTP (default: -1.00 dBTP)

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
