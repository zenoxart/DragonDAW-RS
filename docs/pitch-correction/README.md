# Pitch correction

- **Dragon Tune** (an insert effect) corrects live or recorded vocals in real time: key and scale, retune speed, humanize, flex-tune, vibrato, note stabilizer, doubler.
- **Notes in Audio repair** (double-click a clip › Audio repair › Notes) shows the detected notes as blobs with their pitch curves; drag them to new pitches, flatten drift and vibrato.
