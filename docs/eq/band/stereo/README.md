# Prism (parametric EQ) › Band › Stereo

[Back to Band](../README.md) · [Prism (parametric EQ)](../../README.md)

Which part of the stereo signal the band works on: both, mid, side, left or right.

Part of **Prism (parametric EQ)** – 7-band parametric EQ with shelves, cuts and notch per band.

**Range:** Options: Stereo, Mid, Side, Left, Right (default: Stereo)

Every band has this control; pick the band with the band buttons.

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
