# Purify (voice cleanup) › De Esser › Deesser detection

[Back to De Esser](../README.md) · [Purify (voice cleanup)](../../README.md)

Sets the deesser detection.

Part of **Purify (voice cleanup)** – Post-production vocal chain in one plugin (after zenoxart/CleanVoice): valve vari-mu, leveller, vari-mu, de-esser, two 4-band multibands, parallel presence, oversampled saturation and a resonance suppressor.

**Range:** Options: Single vocal, Allround (default: Single vocal)

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
