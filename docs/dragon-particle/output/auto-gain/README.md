# Philosopher's Stone (one-knob mastering) › Output › Auto gain (A/B at equal loudness)

[Back to Output](../README.md) · [Philosopher's Stone (one-knob mastering)](../../README.md)

The output level after the effect, to match the loudness before and after (compare with the power button).

Part of **Philosopher's Stone (one-knob mastering)** – One-knob mastering: tone EQ with character, transient punch, glue compression, tube colour, widening, a soft clipper and a true-peak limiter, with auto gain for honest A/B.

**Range:** On / off (default: off)

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
