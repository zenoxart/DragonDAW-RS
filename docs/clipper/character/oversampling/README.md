# Obsidian (soft clipper) › Character › Oversampling

[Back to Character](../README.md) · [Obsidian (soft clipper)](../../README.md)

Sets the oversampling.

Part of **Obsidian (soft clipper)** – Soft clipper with the sound of the Fruity Soft Clipper: clean below the threshold, a smooth shoulder up to the ceiling, post gain; plus input drive, soft / hybrid / hard shapes, up to 4× oversampling and a clip-only listen.

**Range:** Options: Off, 2×, 4× (default: 4×)

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
