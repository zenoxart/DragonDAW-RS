# Dragon's Lair (reverb) › Tone › Damping

[Back to Tone](../README.md) · [Dragon's Lair (reverb)](../../README.md)

Rolls off the high frequencies of the tail as it decays, like soft surfaces in a room.

Part of **Dragon's Lair (reverb)** – Room/hall/plate reverb (8-line FDN) with pre-delay, damping and width; early reflections and late reverb each have their own level and EQ.

**Range:** 1.00 kHz … 20.00 kHz (default: 7.00 kHz, logarithmic scale)

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
