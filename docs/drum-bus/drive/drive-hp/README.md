# Dragonforge (drum bus) › Drive › Drive high-pass

[Back to Drive](../README.md) · [Dragonforge (drum bus)](../../README.md)

Sets the drive high-pass.

Part of **Dragonforge (drum bus)** – Drum bus processor: input with target meter, drive (three colours, high-pass), harmonics (50 / 80 Hz focus), compression (glue / punch, mix), lift, five-band harmonic EQ in 1 dB steps, parallel Sub / Low / Loud / Grit, output.

**Range:** 10.0 Hz … 120 Hz (default: 20.0 Hz, logarithmic scale)

Right-click the control for its menu: type a value, **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
