# Athanor (multiband saturator) › Band › Style

[Back to Band](../README.md) · [Athanor (multiband saturator)](../../README.md)

Chooses the variant of the processing; each option changes the character of the effect.

Part of **Athanor (multiband saturator)** – Multiband saturation: up to four bands (Linkwitz–Riley crossovers), each with a style (clean / warm tube, tape, transformer, soft / hard clip, foldback, rectify), drive, dynamics, tone, level, mix and a resonant feedback loop.

**Range:** Options: Clean tube, Warm tube, Tape, Transformer, Soft clip, Hard clip, Foldback, Rectify (default: Warm tube)

Every band has this control; pick the band with the band buttons.

## Mathematics

The band's waveshaper (table above).

**Knob position → value.** A choice of 8: the value is the option's index $0 \dots 7$.

**Smoothing.** Takes effect at once (no glide).

Right-click the control for its menu: **Set value…** (a box with the current value: type a new one in the control's units – `-6 dB`, `250 ms`, `2.5k`, `30L` – and press Enter; one undo step), **Reset to default**, **Copy value** / **Paste value** (between any two knobs; a value of another unit lands at the same position on the scale), MIDI learn, an automation lane, and **Help**, which opens this page.

Drag up / down to turn it (Shift: fine), turn the mouse wheel over it, double-click or Ctrl+click to reset.
