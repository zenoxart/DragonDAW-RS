# Audio repair

Double-click an audio clip › **Audio repair…**: a spectrogram with time and time × frequency selection, and the repair tools – de-noise (learned noise profile), de-hum (50 / 60 Hz found automatically), de-click, de-clip, and spectral attenuation of the selected area. Every repair is one undo step.
